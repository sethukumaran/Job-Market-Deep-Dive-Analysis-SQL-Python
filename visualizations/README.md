# Visualizations

This folder contains the charts generated from the job-market analysis.

1. `01_category_volume.png` — job records by category
2. `02_company_volume.png` — top companies by job records
3. `03_open_jobs_trend.png` — daily open-job trend
4. `04_fresher_share_trend.png` — daily fresher-friendly share
5. `05_skill_demand.png` — top skills by aggregated job mentions
6. `06_fresher_by_category.png` — fresher-friendly share by category

All charts were generated using Python and Matplotlib.
